# 薄荷小陪伴

一个使用视频角色制作的 Windows 桌面宠物。她会悬浮在桌面上，支持拖动、点击互动、随机散步、睡眠、大小调整、始终置顶和系统托盘。

## 项目结构

- `v4/`：当前开发版本（1.3.0），包含双角色、透明帧动画、本地对白和 Fish Audio 语音。
- `v3/`、`v2/`：历史迭代版本，便于回溯实现。
- 根目录：最初原型。
- `assets/`：原始图片、角色模型和图标等源资源。

## 运行最新版本

需要 Node.js 20 或更高版本。

```powershell
cd .\v4
npm.cmd install
npm.cmd run check
npm.cmd start
```

## 打包 Windows 便携版

```powershell
cd .\v4
npm.cmd run dist
```

生成文件位于 `v4/release/MintPet-1.3.0-portable.exe`。

## 操作

- 拖动角色：移动到桌面任意位置
- 点击角色：触发表情、动作和随机对话
- 右键角色：打开设置菜单
- 点击托盘图标：显示或隐藏宠物
- 托盘右键：调整大小、自动散步、置顶、睡眠或退出

角色视觉素材由用户提供视频的抽帧联系表作为身份与造型参考，使用内置 ImageGen 生成，随后以本地 FFmpeg 完成透明背景处理。
